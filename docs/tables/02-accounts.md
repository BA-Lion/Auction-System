# accounts — 用户钱包表

整理日期：2026-11-17。依据 [confirm-design v1.1](../confirm-design/README.md)；共同约定与待定边界见 [目录说明](./README.md)。

## 字段

| 字段 | 含义及已确定约束 |
| --- | --- |
| id | 账户主键 |
| 用户关联（物理字段名待定） | 唯一关联 users.id，同一用户一个钱包 |
| balance | 可用余额，整数分 |
| frozen_balance | 冻结金额，整数分 |
| created_at | 创建时间 |
| updated_at | 修改时间 |

## 约束与业务使用

约束：主键 id；用户关联唯一；资金操作不得形成不允许的负余额。原 owner_type／owner_id 是否直接改为 user_id 尚未确定。

不建立平台总账户、场次平台子账户，不增加归集、关闭子账户的状态字段。平台营收由订单分账与平台收入流水表达。

| 动作 | balance | frozen_balance |
| --- | --- | --- |
| 报名冻结 D | −D | +D |
| 未中拍解冻 D | +D | −D |
| 正常成交，尾款 R | −R | −D |
| 正尾款超时 | 不变 | −D |
| 卖家取得结算或补偿 S | +S | 不变 |

成交和超时直接消耗冻结金额，不先解冻。扣款前核验对应报名的 FROZEN 状态及金额，不能仅检查钱包总冻结金额。当前仅有竞拍押金冻结时，冻结总额等于该用户全部 FROZEN 报名押金之和。

钱包与业务状态、流水在同一数据库事务更新；涉及多个用户钱包时，账户 ID 去重后统一升序加锁。
